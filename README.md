# Customer Shopping Behavior Analysis

## Project Overview

Customer Shopping Behavior Analysis is an end-to-end data analytics project focused on understanding customer purchasing patterns and generating actionable business insights from retail transaction data.

The project uses Python, SQL, and Power BI to demonstrate a complete analytics workflow, from data preparation and exploratory analysis to business analysis, visualization, and reporting.

## Objectives

- Analyze customer purchasing behavior
- Identify customer segments and purchasing patterns
- Evaluate product and category performance
- Analyze factors influencing customer purchases
- Generate actionable business insights
- Build an interactive dashboard for business decision-making

## Tech Stack

- **Python** – Data cleaning, preprocessing and exploratory data analysis
- **SQL** – Business analysis and KPI generation
- **MySQL** – Database management and querying
- **Power BI** – Interactive visualization and dashboarding
- **Jupyter Notebook** – Data analysis

## Project Workflow

### 1. Data Preparation & Exploratory Analysis

The customer shopping dataset is imported into Python and prepared for analysis through data exploration, cleaning, transformation, and validation.

### 2. SQL Analysis

The cleaned data is loaded into a relational database and analyzed using SQL to answer business questions related to:

- Customer behavior
- Customer segments
- Product performance
- Purchasing patterns
- Sales and revenue trends

### 3. Power BI Dashboard

An interactive Power BI dashboard is used to visualize key business metrics, customer behavior, product performance, and purchasing trends.

### 4. Business Insights

The analysis is used to identify meaningful patterns and develop data-driven recommendations related to customer engagement, sales, and business performance.
